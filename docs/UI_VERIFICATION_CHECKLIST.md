# UI 검증 체크리스트

## 1. 대시보드(방 카드 / 로그)

- [ ] `http://127.0.0.1:3100` 접속 시 Next.js 대시보드 메인 페이지가 로드되는지 확인
- [ ] 방 카드(RoomCard) 각각에 다음 정보가 표시되는지 확인
  - [ ] 방 이름
  - [ ] 방 ID (`ID 123456789` 형식, 클릭 시 클립보드에 복사)
  - [ ] 기능 토글(환영 / 브로드캐스트 / 스케줄 / AI 응답)
- [ ] 아바타 영역
  - [ ] 아바타 이미지가 있는 방은 `/avatar/{roomId}` 이미지를 사용해 원형 썸네일이 표시된다.
  - [ ] 아바타가 없는 방은 **fallback 이니셜 썸네일**이 표시된다.
    - [ ] `room-avatar room-avatar-fallback` 클래스로 방 이름 첫 글자가 렌더링되는지 확인
    - [ ] 이미지 로드 실패(onError) 후에도 카드가 비어 보이지 않고 기본 썸네일이 유지되는지 확인
  - [ ] 아바타 교체 아이콘(`?`) 클릭 시 파일 선택 다이얼로그가 뜨고, 업로드 후 새 이미지가 반영되는지 확인
- [ ] 각 방 카드 하단 로그(LogViewer)에 최근 메시지가 표시되고, SAFE_MODE가 ON일 때도 **표시는 유지되지만 발신은 발생하지 않는지** 확인

## 2. 템플릿 관리 페이지(`/templates`)

- [ ] 좌측 카테고리/검색 영역
  - [ ] 카테고리 드롭다운에 다음 옵션이 존재하는지 확인
    - [ ] `환영 (N개)`
    - [ ] `브로드캐스트 (N개)`
    - [ ] `스케줄 (N개)`
  - [ ] 각 옵션의 `(N개)` 값이 실제 템플릿 개수와 일치하는지 확인
  - [ ] 검색 입력창에 키워드를 입력하면, 해당 카테고리 내에서 제목/이름 기준으로 필터링되는지 확인
  - [ ] 선택된 카테고리에서 템플릿이 하나도 없을 경우, 리스트 영역에 “해당 카테고리에 템플릿이 없습니다.” 메시지가 표시되는지 확인
- [ ] 우측 편집/미리보기 영역
  - [ ] 템플릿 선택 시 제목/내용/이미지/멘션 정보가 편집 폼에 채워지는지 확인
  - [ ] 내용 수정 시 카카오톡 미리보기에 실시간으로 반영되는지 확인
  - [ ] 저장 버튼 클릭 시 템플릿이 정상 저장되고, 좌측 리스트/카테고리 개수(N개)가 갱신되는지 확인

## 3. 기능별 관리 페이지(`/settings`)

- [ ] 상단 SAFE_MODE 정보
  - [ ] SAFE_MODE 상태 문구가 다음과 같이 표시되는지 확인  
    - ON일 때: `SAFE_MODE: ON (모든 발신 차단: 수신/로그 전용)`
    - OFF일 때: `SAFE_MODE: OFF (발신 허용 모드)`
  - [ ] SAFE_MODE 체크박스를 ON/OFF하면 문구가 즉시 변경되고, 저장 후 `runtime.json.safeMode` 값이 실제로 반영되는지 확인
  - [ ] SAFE_MODE가 OFF일 때 상단에 붉은 경고 배지가 표시되는지 확인 (실제 방으로 발신될 수 있음 안내)
- [ ] 템플릿 선택 섹션
  - [ ] 각 기능 행에 다음 라벨이 표시되는지 확인  
    - `환영 (N개)` / `Broadcast (N개)` / `Schedule (N개)` 형식으로 템플릿 개수가 함께 노출
  - [ ] 드롭다운에서 템플릿을 선택하고 저장 시, `runtime.json.templateByFeature`에 해당 키/이름이 반영되는지 확인
  - [ ] 서버에 존재하지 않는 템플릿 이름이 `runtime.json.templateByFeature`에 남아 있을 경우:
    - [ ] 페이지 상단에 “템플릿 경고” 박스가 나타나는지 확인
    - [ ] 경고 내용에 어떤 카테고리/이름이 누락되었는지 명시되는지 확인
    - [ ] 다른 템플릿으로 변경 후 저장하면 경고가 사라지는지 확인
- [ ] Talk API 설정
  - [ ] Talk API 사용 여부 체크박스, Base URL, Auth Header 입력 필드가 표시되는지 확인
  - [ ] 값 변경 후 저장 시 `/runtime`의 `talkApi` 섹션이 갱신되는지 확인 (현재는 실험용, 실제 발신은 SAFE_MODE 및 enabled 플래그로 보호됨)

## 4. SAFE_MODE 동작 UI 확인

- [ ] SAFE_MODE를 ON으로 두고:
  - [ ] 대시보드에서 기능 토글(환영/브로드캐스트/AI)을 ON/OFF 하더라도, 실제 카카오톡 방으로 메시지가 발송되지 않는지 확인
  - [ ] `/send/talkapi/dispatch` 호출 시 403 `SAFE_MODE` 에러가 반환되는지 확인
  - [ ] 로그에는 “SAFE_MODE on: skip ...” 류의 경고가 남고, 메시지 본문은 전송되지 않는지 확인
- [ ] SAFE_MODE를 OFF로 전환 후:
  - [ ] 허용 방 + ON된 기능에 대해서만 발신이 이뤄지는지 확인
  - [ ] 제외 방/기능 OFF인 방에는 여전히 발신되지 않는지 확인

## 5. RAG 관련 UI 검증 (KB 탭 / 링크 유무)

- [ ] KB 관련 페이지(예: `/kb`)에서:
  - [ ] “사알못 다시보기 링크”, “12월 3일에 강의 있나” 질문에 대해, 응답에 포함된 링크가 실제 카페 게시글 URL인지 확인
  - [ ] “엉뚱한 일반 질문”일 때는 “정보 없음” 류의 안내만 나오고, 카페 링크/CTA가 추가로 붙지 않는지 확인
