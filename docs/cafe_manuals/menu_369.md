​

카카오톡 대화내용 읽어와서 입퇴장 감지 같은거 하는 그 DB봇 아닙니다.

설명

SQLite를 사용하여 실제로 데이터베이스에 값을 넣거나 지웁니다.

메신저봇에만 있는 DataBase와, 카톡봇 표준 API(API2)에 있는 Database는 이름만 데이터베이스고 실제로는 그냥 파일 입출력입니다.

Database는 표준 API이기에 채팅 자동응답 봇에도 구현되어 있습니다.

다운로드

레퍼런스

new SQLite();

 - 생성자, 생성자는 매개변수를 받지 않습니다.

​

void open(path);

 - 쿼리문을 실행하기 위해 .db 파일을 엽니다

 - file : 데이터베이스가 저장된 파일의 경로

​

Cursor/void query(sql);

 - SQL 쿼리문을 실행합니다.

 - sql : 실행할 SQLite 쿼리문

 - select 명령어를 실행한 경우, android.database.Cursor 클래스의 인스턴스를 반환합니다.

 - 해당 인스턴스는 select 명령어를 실행한 결과를 담고 있는 반복자(iterator)입니다.

 - 나머지 명령어를 실행한 경우, 반환값이 없습니다.

 - 넘긴 쿼리문은 무지성으로 실행하니, 인젝션 등은 알아서 막으세요.

​

void close();

 - .db 파일을 닫습니다.
