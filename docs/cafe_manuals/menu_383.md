1. 안내사항

본 강의는 중급자 이상의 사용자에게 권장합니다.

숙달되지 않은 상태에서 사용하였다가 발생하는 피해에 대해서는 책임지지 않습니다.

1. 루팅된 핸드폰

참고로 저는 Iris에 대한 지식이 충분하지 않기 때문에 강의의 질이 떨어질 수 있습니다. 참고해주세요.

1. Termux 기본 설정

//패키지 업데이트하기

​

문장이 모두 출력된 이후 adb 도구를 설치하기 위해 아래 명령어를 입력합니다.

//adb 도구 설치하기
pkg install android-tools

다음으로 파일을 다운받기 위해서 wget를 설치해줄게요
