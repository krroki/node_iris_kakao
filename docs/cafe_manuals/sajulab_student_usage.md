# Sajulab.kr 사용 매뉴얼 (수강생 관점)

> 이 문서는 **사알못 사주자동화 강의 수강생**이 Sajulab.kr 사이트를 이용해  
> 사주 분석을 요청하고 결과를 확인하는 과정을 정리한 매뉴얼이다.  
> 운영자·관리자 설정(포인트 충전, 로고/PDF 템플릿, SMTP 설정 등)은 다루지 않는다.

---

## 1. 접속 및 로그인

- **접속 주소**
  - 기본 URL: `https://sajulab.kr`
  - 강의 오리엔테이션 또는 카페 공지에서 제공된 링크를 통해 접속해도 된다.

- **로그인 절차**
  1. 메인 페이지 상단의 **“로그인” 버튼**을 클릭한다.
  2. 로그인 화면에서:
     - **이메일**: 강의에서 안내받은 이메일 계정 입력
     - **비밀번호**: 강의에서 안내받은 초기 비밀번호 입력  
       (처음 로그인 후 비밀번호 변경이 안내되면 지시에 따라 변경)
  3. **로그인/Submit 버튼**을 눌러 대시보드로 이동한다.

로그인에 성공하면, 상단 네비게이션에 **대시보드, 주문(또는 주문/분석), 포인트** 등의 메뉴가 보인다.

---

## 2. 화면 구조와 주요 메뉴 (수강생이 주로 쓰는 곳)

### 2.1 주문 관리 (/orders)

- **역할**: 내 사주 분석 요청(“주문”)을 등록하고, 상태를 확인하는 곳.
- 주요 구성:
  - 주문 목록 테이블
    - 고객 이름, 생년월일, 상품, 상태(대기/진행중/완료 등), 생성일시가 표시된다.
  - 상단/우측에 있는 **“새 주문 등록” 버튼**  
    - 실제 UI에서는 “명식 등록”, “주문 등록” 등으로 표시될 수 있다.
  - 각 행 오른쪽의 **행별 액션 버튼들**
    - 편집(수정) 버튼
    - 메모 보기/수정 버튼
    - 분석 시작 버튼
    - 결과/PDF 보기 버튼

### 2.2 포인트 내역 (/points)

- **역할**: 현재 보유 포인트와 사용/충전 이력을 확인하는 곳.
- 구성:
  - 상단에 **현재 포인트 잔액** (예: 101,299,000P)
  - 아래 표에 포인트 내역이 시간 순으로 표시
    - “사용” 항목: 분석 1회 요청 시 차감된 포인트 (예: -500P)
    - “충전” 항목: 운영자가 충전한 포인트 (예: +1,300,000P 등)

### 2.3 대시보드 (/dashboard)

- **역할**: 전체 요약을 한눈에 보는 화면.
- 표시되는 내용 예:
  - 포인트 잔액
  - 오늘 기준 진행 중/완료된 분석 건수
  - 최근 주문(분석 요청) 리스트 요약

> **수강생 관점에서 꼭 필요한 메뉴는**  
> `주문(분석)` / `포인트` / `대시보드` 3가지만 충분하며,  
> `고객`, `상품`, `설정` 메뉴는 운영자/관리자용이므로 건드릴 필요가 없다.

## 3. 새 분석 요청(주문) 만드는 방법

> 사알못 강의에서 실제로 사용하는 “사주 분석 요청” 흐름을 기준으로 정리했다.

### 3.1 주문 등록 화면 열기

1. 상단 메뉴에서 **“주문” 또는 “주문/분석 관리” 메뉴**를 클릭한다. (URL: `/orders`)
2. 주문 목록 화면 상단에서 **“새 주문 등록” 버튼**을 클릭한다.
   - UI에 따라 “명식 등록”, “주문 등록”, “새 분석 요청” 등으로 보일 수 있다.
3. 주문 등록용 **팝업/모달 창**이 뜨면, 아래 항목을 순서대로 채운다.

### 3.2 입력 항목 (수강생이 채우는 값)

실제 필드 이름은 UI에 따라 약간 다를 수 있으나, 구조는 다음과 같다.

1. **이름**
   - 본인 이름 또는 상담 대상자의 이름을 입력.
2. **성별**
   - 남/여 중 하나를 라디오 버튼으로 선택.
3. **생년월일**
   - 연/월/일을 각각 선택하는 **3개의 드롭다운(select)** 로 구성.
   - 예: 1990년 / 1월 / 4일
4. **양력/음력**
   - 라디오 버튼으로 **양력/음력** 중 하나를 선택.
5. **출생 시간**
   - “1430”처럼 **4자리 숫자(시분)**로 입력.  
   - 새벽/오전/오후 등은 강의에서 안내한 기준에 맞춰 입력한다.
6. **이메일**
   - 분석 결과 안내를 받을 이메일 주소.  
   - 형식: `example@email.com`
7. **연락처(전화번호)**
   - 형식 예시: `010-1234-5678`
8. **메모**
   - 선택 입력.
   - 분석 목적, 현재 고민, 특별히 보고 싶은 부분 등을 자유롭게 적는다.
9. **상품 선택**
   - 사이트에 등록된 사주 분석 상품 중 하나를 선택. (예: `saju-data`, `사주 분석 리포트` 등)
   - 강의에서 지정한 상품이 있다면 그 상품만 선택한다.

### 3.3 주문 등록 완료

1. 모든 필드를 채운 뒤, 모달 하단의 **“등록/저장” 버튼**을 클릭한다.
2. 잠시 후 주문 목록에 새 행이 추가되고, 이름/생년월일/상품 등이 보이면 **등록 성공**이다.
3. 동시에 **포인트 페이지(/points)** 에서는
   - “사용 -500P (분석 요청 1건)”처럼 분석 1건당 차감된 포인트가 기록된다.  
     (정확한 차감 포인트 값은 운영 정책에 따라 다를 수 있지만, 테스트에서는 1건당 500P로 동작한다.)

## 4. 분석 실행과 결과(PDF) 확인

### 4.1 분석 시작

1. 주문 목록에서 방금 등록한 주문의 행을 찾는다.
2. 행 오른쪽에 있는 **“분석 시작” 버튼** 또는 분석 아이콘을 클릭한다.
   - 테스트 기준으로, 이 버튼의 title은 `"분석 시작"` 또는 `"분석"` 으로 설정되어 있다.
3. 버튼을 누르면 상태가 **“대기 → 분석중 → PDF생성중 → 완료”** 순서로 바뀌며,
   상태 필터 버튼(전체/대기/완료/실패 등)을 통해 현재 진행 상황을 확인할 수 있다.

### 4.2 결과/PDF 보기

1. 상태가 “완료”로 바뀌면, 같은 행에 **PDF/결과 보기 버튼**이 활성화된다.
2. “PDF” 아이콘 또는 “결과 보기” 버튼을 클릭하면:
   - 새 창/탭에서 PDF가 열리거나,
   - 브라우저 내장 뷰어에서 PDF가 표시된다.
3. 수강생은 이 PDF를 통해:
   - 사주 분석 결과,
   - 정리된 리포트,
   - (강의에서 정의한) 주요 지표들을 확인하고 필요시 저장/다운로드한다.

> **주의:**  
> 브라우저가 팝업 차단을 하고 있을 경우, PDF 탭이 안 열릴 수 있다.  
> 이 때는 sajulab.kr 도메인에 대해 팝업 허용 후 다시 시도한다.

---

## 5. 포인트 관리 (수강생 입장에서 확인할 것)

1. 상단 메뉴에서 **“포인트”** 또는 `/points` 페이지로 이동한다.
2. 상단에는 현재 보유 포인트가 크게 표시된다.
3. 아래 표에는 다음 정보가 시간순으로 표시된다.
   - **날짜/시간**
   - **유형**: `사용` / `충전`
   - **변동 포인트**: 예) `-500P`, `+1,300,000P`
   - **잔여 포인트**
   - **설명**: “분석 요청 1건”, “운영자 수동 충전” 등
4. 수강생은:
   - “새 분석 요청 1건 → 사용 -500P 기록 증가”처럼  
     본인의 분석 요청과 포인트 사용 내역이 일치하는지 확인한다.

포인트 충전 자체(얼마를 충전할지, 언제 충전할지)는 운영자 측에서 관리하는 영역이며,  
수강생은 **“얼마를 썼는지/얼마가 남았는지”만 확인하는 용도**로 사용한다.

---

## 6. 정리 – 수강생이 Sajulab.kr에서 하는 일

1. **로그인**: 강의에서 발급받은 계정으로 sajulab.kr 접속·로그인
2. **새 분석 요청 등록**
   - 주문 페이지에서 새 주문 등록
   - 이름/성별/생년월일/양력·음력/시간/이메일/연락처/메모/상품을 입력
3. **분석 실행**
   - 주문 목록에서 “분석 시작” 버튼으로 분석 실행
   - 상태 배지를 통해 진행 상황 확인
4. **결과 확인**
   - 완료 후 PDF/결과 보기 버튼으로 분석 리포트 확인·저장
5. **포인트 확인**
   - 포인트 페이지에서 사용/충전 내역과 잔여 포인트 확인

이 매뉴얼을 기준으로, RAG/봇은 “sajulab 사이트 사용법” 관련 질문에  
**수강생 관점에서 단계별 흐름을 설명하는 답변**을 생성해야 한다.
