# [KB] 운영 용어/인물 정의

RAG 답변이 자주 흔들리는 용어/인물에 대해, **카페 운영 관점의 정의(SSOT)** 를 고정한다.

## 다시보기
- 의미: **무료특강 라이브가 종료된 이후**, 해당 무료특강을 **유료 다시보기(VOD)** 로 제공하는 것을 말한다.
- 금액: “무료특강 종료 후 다시보기(유료)” 구조이며, **정확한 금액(예: 2~3만원대 등)은 해당 공지/게시글에 명시된 값만** 사용한다. (예시 링크를 하드코딩하지 않는다)
- 링크/노출 정책:
  - 답변에서는 **카페 글 URL만** 제공한다.
  - **계좌번호/연락처/오픈채팅/인스타·스레드·유튜브 등 외부 링크/외부 계정**은 노출하지 않는다.

## 인물(카페 운영 정의)
- **마케터제이**: 디하클 카페 **대표(운영자)**
- **룰루랄라릴리**: 디하클 카페 **강사**

## 강의명/프로그램명(카페 관행)
- 디하클 강의/특강은 “쇼츠투벤츠”, “AI 마스터즈”처럼 **특색 있는 고유명(프로그램명)** 을 붙이는 경우가 많다.
- 신청 게시판 SSOT:
  - 무료특강 신청: 메뉴 23
  - 정규강의 신청: 메뉴 42
- 처리 원칙:
  - 사용자가 고유명(프로그램명/기수/별칭)을 포함해 질문하면, RAG는 해당 고유명이 **제목/본문에 실제로 포함된 글**만 최종 후보로 사용한다(추측/오탐 방지).
  - 고유명 없이 “가장 최근 강의/다음 강의”처럼 포괄 질문이면, 신청 게시판(무료특강/정규강의) **최신 글**로 결정적으로 답한다.
  - 고유명은 매번 새로 생길 수 있으므로 **하드코딩하지 않고**, 실제 수집된 글 제목/본문에서만 근거를 찾는다.

## 답변 규칙(핵심)
- “누구야/정체/소개” 질문:
  - 위 인물 정의 + **카페 글 근거 1~3개**만 제시한다.
  - 실명/수익/가족관계/외부 프로필 등 **추측 금지**.
- “다시보기 링크” 질문:
  - 질문에 포함된 **날짜/키워드가 동일하게 포함된 글**만 링크한다.
  - 일치 문서가 없으면 **없음/확인 불가**로 답하고, 날짜가 다른 예시 링크를 섞어 제공하지 않는다.

## 카페 메타(회원수/멤버수)
- 의미: 디하클 네이버 카페의 현재 멤버수(가입자 수).
- 처리 정책: KB 수집 데이터로 답하지 않고, 카페 홈(카페정보) HTML에서 실시간 파싱하여 결정적으로 제공한다(`diag.mode=cafe_member_count`).
- 실패 시: 숫자를 추측/생성하지 말고 “자동 조회 실패”로 안내한다.
