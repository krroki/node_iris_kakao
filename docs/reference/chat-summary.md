# 채팅 요약/질문(chatSummary)

## 켜는 방법
- 기능 토글: `runtime.features[roomId].chatSummary=true`
- 트리거: `!채팅요약`, `!요약`
- 처리 위치: `node-iris-app/src/controllers/CustomMessageControllerBang.ts`
- KB 엔드포인트:
  - 요약: `POST /chat/summary` (기본 `http://127.0.0.1:8610`)
  - 질문 답변(Q&A): `POST /chat/qa` (기본 `http://127.0.0.1:8610`)

## 사용법

### 1) 요약(기존)
- 기본(오늘 자정~현재 + 최근 300개):
  - `!요약`
  - `!채팅요약`
- 롤링 범위(최근 N시간/일 + 최근 300개, 최대 7일=168시간):
  - `!요약 24시간`
  - `!채팅요약 6시간`
  - `!채팅요약 2일`

### 2) “채팅 내용 기반 질문”(신규)

> 목적: 최근 채팅 로그를 근거로 “방에서 오간 내용 중 원하는 주제”에 대해 질문하고 답을 받는다.

- 기본(오늘 자정~현재 + 최근 300개):
  - `!요약 당근 비즈니스 가입 안되면 어떻게 해?`
- 기본(기간 미지정 Q&A의 기본 범위):
  - 질문이 포함된 `!요약 <질문>`은 기본으로 **최근 72시간(3일)** 로그를 사용한다.
- 롤링 범위(최근 N시간/일 + 최근 300개, 최대 7일=168시간):
  - `!요약 24시간 당근 비즈니스 가입 안되면 어떻게 해?`
  - `!요약 2일 지난 이슈 결론이 뭐였어?`

동작 규칙(중요):
- Q&A는 **대화 로그에 나온 내용만** 근거로 답한다(로그에 없으면 “확인 불가”로 안내).
- 외부 카페 글/매뉴얼(RAG)은 조회하지 않는다(채팅 요약/질문 기능은 로그 기반 기능).

## 데이터 소스(로그)
- 원본 로그 파일: `node-iris-app/data/logs/<roomId>/<YYYY-MM-DD>.log` (JSONL)
- Node가 최근 로그를 로드해 KB에 `messages[]`로 전달한다.
