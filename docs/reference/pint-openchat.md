# 4.pint 오픈채팅 운영

> 목적: `18475321871585649` 서비스방에서만 Pint 데이터 기반 안내를 제공한다.
> 다른 방에는 Pint 커맨드나 전용 welcome이 동작하지 않는다.

---

## 1. 적용 범위

- 서비스방: `18475321871585649`
- 테스트 운영 알림방: `18475752914588021`
- Pint 커맨드는 서비스방과 테스트 명령방에서만 활성화한다.
- Pint 전용 welcome은 서비스방에서 `features[roomId].pintServiceWelcomeOnly=true`일 때만 활성화한다.

---

## 2. 서비스방 전용 Welcome

### 조건

- `features[18475321871585649].welcome=true`
- `features[18475321871585649].pintServiceWelcomeOnly=true`
- `features[18475321871585649].welcomeFollowUp=false`

### 동작

- 입장 시 텍스트 welcome 1회만 발송한다.
- 하트스샷, 닉네임 검증, 오픈프로필 후속 검증은 시작하지 않는다.
- 환영 문구는 시간대별 짧은 인사 풀에서 1줄만 고른다.
  - 아침: 좋은 아침/굿모닝 계열
  - 낮: 안녕하세요/좋은 오후 계열
  - 저녁: 수고했어요/좋은 저녁 계열
  - 심야: 늦은 시간/좋은 밤 계열
- 명령어 소개, CTA, 데이터 수치 훅은 붙이지 않는다.
- 최종 fallback 템플릿: `node-iris-app/config/templates/welcome/welcome_pint_service_room.json`

---

## 3. Pint 커맨드

### 명령어

- `!도움말`
- `!이슈`
  - 옵션: `!이슈 1h`
- `!밤새 [쇼츠|롱폼|전체]`
- `!핫영상 [쇼츠|롱폼|전체]`
- `!신규`
- `!급상승`

### 응답 규칙

- `!밤새`, `!핫영상`, `!급상승`은 신뢰도 낮은 채널을 제외한다.
  - 현재 기준 1: 구독자 100만 초과 고래 채널 제외
  - 현재 기준 2: 일조회수/구독자 비율이 비정상적으로 높은 이상치 채널 제외
  - hot-videos는 Pint 홈 `topChannels`의 채널 ID/채널명 매핑으로 필터링한다.
- `!이슈`, `!이슈 1h`는 더 이상 `언급 n회, 커뮤니티 n곳`을 쓰지 않는다.
  - `!이슈`: `24h 조회 / 댓글`
  - `!이슈 1h`: `1h 조회 / 댓글`
  - 정렬 기준은 `댓글 내림차순 → 조회 내림차순`이다.
  - 윈도우 delta가 없으면 누적 `조회 / 댓글`로 폴백한다.
  - 약한 항목을 억지로 채우지 않도록 최소 임계치를 통과한 이슈만 보여준다.
  - 빈 결과면 다른 명령으로 넘어갈 수 있게 CTA를 같이 붙인다.
- `!급상승`은 발굴용 랭킹으로 별도 취급한다.
  - 구독 30만 이하 채널만 남긴다.
  - 기업/공식 채널 패턴은 제외한다.
  - 정렬 기준은 `구독 대비 24h 조회 배수 내림차순 → 24h 조회 내림차순`이다.
  - 각 채널에 `구독 대비 24h 조회 n배`를 함께 보여준다.
  - 결과가 적을 때도 그대로 보여주되, 기준을 통과한 채널 개수를 첫 줄에 함께 알린다.

### 자연어 별칭

서비스방/테스트 명령방에서만, `commands=true`일 때 아래 자연어를 `!` 명령 없이 바로 받아준다.

- `요즘 뭐 떠?` → `!핫영상`
- `지금 뭐 떠?` → `!핫영상`
- `뭐 떠 / 뭐떠 / 지금 뭐 뜸?` → `!핫영상`
- `밤새 뭐 올랐어?` → `!밤새`
- `밤새 뭐 뜸?` → `!밤새`
- `오늘 이슈 뭐야?` → `!이슈`
- `이슈 뭐야?` → `!이슈`
- `신규 뭐 있어?` → `!신규`
- `루키 뭐 있어?` → `!신규`
- `급상승 뭐 있어?` → `!급상승`
- `채널 뭐 떠?` → `!급상승`
- `핀트 뭐 할 수 있어?` → `!도움말`

가드레일:

- `!`로 시작하는 기존 명령이 우선이다.
- 길이 24자 초과 일반 문장은 무시한다.
- Pint 허용 방이 아니면 무시한다.

## 4. 자동 브리핑

구성 위치: `node-iris-app/config/runtime.json`

```json
{
  "pintBriefing": {
    "enabled": false,
    "roomId": "18475321871585649",
    "testRoomId": "18475752914588021",
    "allowProdSend": false,
    "timeZone": "Asia/Seoul",
    "graceMin": 10,
    "issues": { "enabled": true, "at": "09:10", "window": "24h" },
    "overnight": { "enabled": true, "at": "10:30", "only": "all" },
    "rookies": { "enabled": true, "at": "15:30" },
    "hotVideos": { "enabled": true, "ats": ["12:00", "16:00", "20:00"], "only": "all" },
    "studioPolling": { "enabled": true, "origin": "https://pint.kr", "pollSec": 10 }
  }
}
```

요약:

- `enabled=true`일 때만 자동 브리핑이 돈다.
- `allowProdSend=false`가 기본이고, `true`일 때만 실방 발송을 허용한다.
- 상태 파일은 `node-iris-app/data/pint_brief_state.json`을 사용한다.
